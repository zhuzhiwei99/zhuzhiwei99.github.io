Selected Publications

Low-Rank Approximation for Efficient Compression of Gaussian Splatting Spherical Harmonics

Zhiwei Zhu, Sicheng Li, Yiyi Liao, Lu Yu
TCSVT, 2026

A systematic study that reveals and leverages the intrinsic low-rank structure of SH coefficients in 3DGS for efficient compression.

Paper Code Bibtex

Dual-Hilbert Scan for Efficient Video-Based Gaussian Splatting Compression

Zhiwei Zhu, Yiyi Liao, Lu Yu
ISCAS, 2026

A GPU-accelerated Dual-Hilbert scan algorithm mapping 3D Gaussians to 2D videos, enabling efficient 3DGS compression over 500× faster than PLAS.

Paper Code Bibtex

Eliminating Geometric Representation Redundancy for 3D Gaussian Splat Coding

Shanchuan Liu*, Zhiwei Zhu*, Sicheng Li, Yiyi Liao, Lu Yu

A lightweight preprocessing method canonicalizing scale and rotation in 3DGS to reduce redundancy.

Paper Code Bibtex

UniGSC: Unified Gaussian Splats Codec

Zhiwei Zhu, Sicheng Li, Yiyi Liao, Lu Yu
Github, 2025

A highly modular framework for compressing static/dynamic Gaussian splats, supporting video and point cloud codecs.
